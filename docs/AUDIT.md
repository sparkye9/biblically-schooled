# Biblically Schooled — Repository Audit (Phase 1)

Audit date: 2026-10-14 · Branch audited: `main` @ `4930bda`

This documents what existed **before** the redesign, what was broken, and the
root cause of each problem. Every later change traces back to an item here.

## 1. Architecture as found

| Area | What exists |
| --- | --- |
| Framework | Next.js 16.3 (App Router), React 19, Tailwind v4, shadcn/base-ui components, lucide-react icons |
| Build config | `next.config.mjs` sets `typescript.ignoreBuildErrors: true` — type errors were hidden from every build |
| State | One React context (`lib/store.tsx`) persisted to `localStorage` key `biblically-schooled-v5`. Seed data is merged into saved data by id on load. |
| Server/database | None. A Postgres/login experiment was removed earlier in favour of an optional view PIN (`components/pin-gate.tsx`). |
| Offline | `public/sw.js` service worker (cache-first for pages and scripts) + `offline.html` |
| Backup | JSON export/import (`lib/data-export.ts`, `components/data-backup.tsx`) |
| Households | Two households: Venessa (Alijah 1st, Olori-Joy K, Seraiah Pre-K) and Damilola (Amelia Pre-K). A switcher picks one household or "Shared". |

### Routes (15 in the sidebar + 3 hidden)
`/` Home · `/today` · `/teaching-guide` · `/bible` · `/children` · `/progress` · `/portfolio` · `/planner` · `/shared` · `/printables` · `/print-center` · `/library` · `/supplies` · `/sunday-prep` · `/settings` · hidden: `/start-school` (guided mode), `/prep`, `/week`, `/kid/[childId]` (child mode), `/lessons/[lesson]` (interactive boards).

### Curriculum data — three parallel, disagreeing sources
1. **`lib/seed.ts`** (the only one the app actually uses): 35 weeks (not 36). Weekly Bible themes (Creation → Revelation), plus a table of one math title and one literacy title per grade per week.
2. **`lib/curriculum.ts`** (384 KB, ~540 detailed lessons with scripts): **never imported anywhere**, and it does not compile (unescaped apostrophes such as `'God's care'`). Its weekly themes ("Senses", "Habitats", "Winter Weather") don't match the seed's Bible themes.
3. **`lib/curriculum-complete.ts`**: a template/notes file, also never imported, also a syntax error.
4. **`lib/worksheets.ts`**: generates metadata for 36 weeks × 3 grades of worksheets whose `fileUrl`s (e.g. `/worksheets/week-04/k/Monday_literacy.html`) **do not exist** on disk.

### Printables on disk (`public/worksheets`, 23 MB)
- 595 PDFs: per child × Mon/Tue/Thu/Fri for weeks 1–35, plus a Parent Checklist per week. Generated by ReportLab / pdf-lib.
- 173 HTML files (a handful of per-grade sample pages; per-child weekly HTML).
- Week 36 has only two sample HTML files and no PDFs.

## 3. Problems found and their root causes

| # | Symptom the family experienced | Root cause |
| --- | --- | --- |
| 1 | **Duplicate worksheets** | Seed plans one math + one literacy title *per week*; the PDF generator printed that same page on Mon, Tue and Thu. Automated scan: **288 of 1,556 PDF pages are exact duplicates** (108 duplicate groups), e.g. Olori-Joy Week 3 "More or Less" identical on Mon/Tue/Thu; Amelia's "Count & Color 1-5" body identical across weeks 5, 8, 9, 10. "Show What You Know" and "Art, Music & Life Skills" pages are near-identical in all 35 weeks. |
| 2 | **Repetitive lessons** | `buildLessons()` in `seed.ts` creates the same lesson (same title, same 3 generic steps: "Introduce X… Model it once… Celebrate") on all four home days. |
| 3 | **Missing worksheet images / broken links** | `lib/worksheets.ts` invents file paths that were never created; the Printables page links to them (404). Lesson `requiredWorksheet` URLs in `curriculum.ts` point to `.pdf` files that don't exist. Some PDFs say "Count the nickels" with no coins drawn (Week 9, Alijah). |
| 4 | **Incorrect answer choices** | Generated PDFs contain duplicate options (Seraiah Week 1: "5 5 4") and duplicate rows ("9 nickels" twice). No answer validation existed. |
| 5 | **Incorrect phonics audio** | `PhonicsBoard` sends spelled-out sounds like `"tuh"`, `"puh"`, `"sss"` to the browser's text-to-speech, which reads them as words or letter names. Stop consonants are given an added "uh" (teaches /tuh/ instead of /t/). `WordBuilder` speaks letter *names* while children build words by *sound*. The board always shows the same six letters regardless of the week. |
| 6 | **Progress not saving** | On `/today`, the completion checkmark only toggled React component state (`useState`) — it never called the store, so ticks vanished on reload. The Teach / Open / Challenge buttons on the same card had no handlers. |
| 7 | **Missed days silently skip lessons** | The current lesson is computed purely from the calendar date. A missed day that isn't entered as a "break" in Settings is consumed anyway, so lessons are skipped; the only remedy was manual admin. |
| 8 | **Difficult navigation** | 15 sidebar items with heavy overlap (Today / Home / Start School / Teaching Guide / Planner; Printables / Print Center; Supplies / Prep / Sunday Prep). Mobile shows 4 items + a "More" menu of 11. |
| 9 | **Incomplete lessons** | The used curriculum has a title only; "teaching guide" text is three generic sentences. 35 weeks, not 36. The detailed content that existed (`curriculum.ts`) was never wired in. |
| 10 | **Inconsistent printables** | Three generators (ReportLab, pdf-lib, hand HTML) with different layouts; no QA. |
| 11 | **Too much parent prep** | No consolidated materials list per day, no "what can I skip" guidance, no low-energy plan. |
| 12 | Hidden type errors | 50+ TypeScript errors (`youNeed`, `teach`, `ask`, `watchFor` used but not on `Lesson`) hidden by `ignoreBuildErrors`. |
| 13 | Stale app after updates | Service worker serves pages and scripts **cache-first**, so a deployed fix may never reach the device. |
| 14 | Today shows only one household | Default view is Venessa's household, so Amelia never appears on the Today screen. |

## 4. Data that must be preserved
`localStorage['biblically-schooled-v5']`: households, children (names, grades, colours, child-mode flags), assignments (completion status + timestamp), skills (status), parent notes, read-aloud list, supplies, custom lessons/resources, school start date, breaks, view PIN. The redesign migrates all of this and leaves the v5 key untouched as a fallback copy.
